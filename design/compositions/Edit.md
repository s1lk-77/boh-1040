# Edit

A GM should be able to [add an ability](reaction:Edit.AddEntry) with a lookup code.

```endpoints
Edit.AddEntry at /edit/add-entry
```

A GM should be able to [update an ability entry](reaction:Edit.UpdateEntry).

```endpoints
Edit.UpdateEntry at /edit/update-entry
```

A GM should be ahble to [update the name of their game](reaction:Edit.UpdateName).

```endpoints
Edit.UpdateName at /edit/update-name
```

A GM should be able to [delete an ability from their game](reaction:Edit.DeleteEntry).

```endpoints
Edit.DeleteEntry at /edit/delete-entry
```

A GM should be able to [remove a player from their game](reaction:Edit.RemovePlayer)

```endpoints
Edit.RemovePlayer at /edit/remove-player
```
